# Design rules

These rules apply to the app, the README, the download page, release notes and every image. Check a change against them before review.

## Do

- Use the night-drive palette and Manrope, as set out in [BRAND.md](BRAND.md).
- Keep text readable: body text at normal size, secondary text that still meets WCAG AA contrast.
- Follow the system light or dark setting everywhere, or nowhere. A page or screen never mixes the two.
- Use color for its usual meaning: green for done, red for errors, amber for Flack's own actions.
- Say each thing once, in plain words. Cut any line that only the author would understand.
- Give pages real sections with real headings.
- Make every button do something real. A contact link is a link, not a button that pretends to be a form.

## Don't

- Number labels with leading zeros (01, 02, 03).
- Put small "eyebrow" text above headlines, in any form: plain, after a dash, or in a pill or chip with a colored dot.
- Put a pill with a glowing or pulsing dot above a headline or call to action.
- Italicize or underline one random word in a headline.
- Use gradient blobs, purple gradients, heavy gradients or glassmorphism.
- Stack a box behind a box for a fake 3D look.
- Add a colored strip along the top or one side of a card, button or block.
- Draw strokes on rounded boxes that get thinner at the corners.
- Make everything a full pill. Buttons and controls use a 12dp radius.
- Use bento grids, a generic startup look or a tan page with big calls to action.
- Use Inter, Space Grotesk, Geist Mono or the trendy editorial serif.
- Add scroll-triggered reveals, sliding text carousels, pulsing list dots or oversized cursor effects.
- Add a newsletter signup or any slot that exists only because a template had one.
