# Writing rules

Every word in this repository is public: README, docs, app text, release notes, issues, pull requests and commit messages. Write plainly, in sentence case, and say what is true.

## Quick test

Before you keep a sentence, ask:

1. Can I delete this word or phrase without losing meaning? Then delete it.
2. Is this the simplest way to say it? If not, simplify.
3. Would I say this out loud to a colleague? If not, rewrite.
4. Does this add information, or only sound impressive? If the second, cut it.

## Words to delete or replace

| Word | Use instead |
| --- | --- |
| comprehensive | "full", "complete", or delete |
| sophisticated | "advanced", or say what makes it complex |
| robust | "reliable", "stable", or delete |
| transformative | "changed", "improved", or be specific |
| leveraging | "using" |
| seamlessly | delete, or describe the actual integration |
| innovative, cutting-edge, state-of-the-art | say what is new |
| holistic | "complete", "full", or be specific |
| synergy | name the actual benefit |
| ecosystem | "system", "environment", or be specific |
| paradigm | only for a real paradigm shift |
| empower | say what the person can now do |
| rich (as in "rich data") | delete, or say what makes it substantial |

## Phrases to delete

"It's worth noting that", "It's important to understand that", "At the end of the day", "When all is said and done", "In today's world", "Moving forward", "Going forward", "In terms of".

Shorten: "In order to" → "To". "Due to the fact that" → "Because". "At this point in time" → "Now". "With respect to" → "About" or "For".

## Intensifiers and redundant modifiers

Delete "very", "extremely", "incredibly", "absolutely", "truly", "literally", "actually", "basically" and "essentially" unless they change the meaning.

"Completely finished" → "finished". "Totally unique" → "unique". "Absolutely essential" → "essential". "Critically important" → "important". "End result" → "result". "Future plans" → "plans". "Past history" → "history". "General consensus" → "consensus". "Close proximity" → "proximity".

## Sentence patterns to rewrite

- **"Not just X, it's Y."** State the thing directly.
- **"Fundamentally transforms" or "represents a fundamental shift."** Describe the actual change.
- **Inflated claims:** "a critical enhancement", "a major milestone", "a significant improvement", "a game-changer", "a breakthrough". Say what was done and let readers judge.
- **Empty transitions:** "With that in mind", "Building on this foundation", "Taking this a step further". Make the next point.
- **Lists of near-synonyms:** "comprehensive, sophisticated, and robust". Pick one or none.
- **Hedging:** "may potentially be able to possibly". Say what you know.
- **Noun stacking:** "production-ready deployment system infrastructure". Use a verb.
- **Passive voice that hides who acted:** "It was determined that". Name who.
- **Circular definitions:** "The system enables users to use the functionality the system provides."

## Tics to avoid

| Tic | Example |
| --- | --- |
| Negation-first reveal | It is not a wrong answer. It is a non-answer. |
| Significance designation | It is the leg that answers the actual question. |
| Abstraction agency | Median hides it. The table shows it. |
| Deferred noun | Five of those six rows are one cluster. The sixth is not. |
| Coy or thesis-shaped header | What "exhausted" means. The one gap that does clear the bar. |
| Aphoristic closer | It is the kind of number that looks like evidence and is not. |
| Straw-man knockdown | "It thinks twice as long" is the obvious reading, and it is wrong. |
| Fragment cadence | Six legs. One GPU, one server build, one sampler, one question set. |
| Dressed metaphor | That is information loss wearing the costume of a style fix. |
| Label-first framing | The left column of this table. |

## Examples

- Instead of "The comprehensive entity extraction system leverages sophisticated algorithms to enable robust knowledge graph construction", write "The entity extraction system builds knowledge graphs from archive records."
- Instead of "This transformative milestone fundamentally reshapes the archive's research capabilities", write "This changes how researchers can use the archive."
